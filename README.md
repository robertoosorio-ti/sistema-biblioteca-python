# 📚 Sistema de Biblioteca en Python

## 📌 Descripción

Proyecto académico desarrollado durante mi formación en Ingeniería en Informática en AIEP, utilizando Python y Google Colab.

El programa permite registrar estudiantes y controlar su ingreso y salida de una biblioteca mediante un menú interactivo en consola.

Este repositorio conserva el código original desarrollado como parte de mi aprendizaje en programación.

## ⚙️ Funcionalidades

- Registrar estudiantes mediante RUT, nombre y carrera.
- Identificar estudiantes registrados anteriormente.
- Registrar fecha y hora de ingreso.
- Controlar la entrada y salida de estudiantes.
- Consultar estudiantes presentes en la biblioteca.
- Buscar estudiantes por RUT.
- Consultar registros de acceso.
- Contabilizar estudiantes registrados por carrera.

## 🛠️ Tecnologías utilizadas

- Python
- Biblioteca estándar `datetime`
- Google Colab (entorno de desarrollo original)

## 💻 Cómo ejecutar el programa

1. Descargar el archivo `biblioteca.py`.
2. Tener Python 3 instalado.
3. Abrir una terminal en la carpeta del archivo.
4. Ejecutar:

```bash
python biblioteca.py
```

El programa mostrará un menú interactivo:

```text
1. ingresar
2. salir
3. listar
4. terminar
```

## 🧠 Conceptos aplicados

- Variables y listas
- Funciones
- Condicionales
- Ciclos `for` y `while`
- Diccionarios
- Entrada de datos mediante `input()`
- Manejo de fechas y horas
- Búsqueda y registro de información
